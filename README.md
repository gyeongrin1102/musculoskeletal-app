# 근골격계질환 증상조사 웹앱

근골격계부담작업 유해요인조사 중 **'징후와 증상 유무'**(안전보건규칙 제657조 제1항)를
온라인으로 받고, 판정·집계·출력·보관까지 처리하는 Streamlit 앱입니다.

## 화면 구성

| 구분 | 화면 | 설명 |
|---|---|---|
| 근로자 | 증상조사 참여 (기본 화면) | 5단계 설문: 기본 사항 → 생활과 병력 → 통증 유무와 부위(신체 그림) → 부위별 세부 문항 → 확인과 제출 |
| 근로자 | 작업자세 촬영 | 작업자세 사진 촬영·제출 |
| 관리자 | 증상조사표 출력·보관 | 응답자별 조사표(Word/PDF, 1인 1파일 ZIP 또는 합본), 연도별 집계·보관 엑셀, 빈 양식, 판정 재계산 |
| 관리자 | 대시보드 / QR / REBA / 유해요인조사표 / 보고서 / 데이터 관리 | 기존 기능 |

## 설문·판정 원칙

- 문항과 보기는 **별지 제2호서식(KOSHA GUIDE E-G-1-2025)** 그대로입니다 (`survey_form.py`).
  보기를 바꾸면 판정 기준과 지난 조사 비교가 어려워지므로 수정하지 마세요.
- 판정 (KOSHA GUIDE E-G-1-2025 8.1 표 2)
  - **관리대상자**: 1주일 이상 지속되거나 *또는* 1달에 1번 이상 발생 + 중간 정도 이상
  - **통증호소자**: 1주일 이상 지속되고 *그리고* 1달에 1번 이상 발생 + 심한/매우 심한
  - **정상**: 위에 해당하지 않음
- 같은 해에 같은 성명·부서·성별로 다시 제출하면 막습니다(중복 제출 방지).
  `survey_results`에 RLS(행 보안)가 걸려 있으면 설문 화면에서 기존 응답을 조회할 수 없으므로,
  Supabase SQL Editor에서 `supabase/survey_duplicate_check.sql`을 한 번 실행해 주세요.
  (실행하지 않으면 중복 확인만 건너뛰고 제출은 정상 저장됩니다.)
- 증상조사 결과는 근골격계질환 이환을 부정하거나 입증하는 근거로 쓸 수 없다는 안내를 첫 화면에 표시합니다.

## 다국어 설문 (한국어·베트남어·중국어)

- 설문 화면 위쪽에서 언어를 고릅니다. 화면 글자만 바뀌고, 응답 값은 항상 한국어 보기로 저장되므로
  판정·집계·출력은 언어와 관계없이 같습니다. 응답 언어는 `응답언어` 칸에 기록됩니다.
- 번역문: `translations/survey_translations.csv` (엑셀로 열어 수정 가능, UTF-8)
  - `ko` 열은 화면의 한국어 원문이며 번역을 찾는 기준이므로 **고치지 마세요.**
  - `vi`(베트남어), `zh`(중국어) 칸을 고치면 됩니다. 빈 칸은 한국어로 보입니다.
  - `{part}`, `{items}`, `{n}`, `{step}` 같은 중괄호 표시는 그대로 두세요(자동으로 값이 들어감).
  - 언어를 늘리려면 열을 추가합니다: `en`, `th`, `uz`, `km`, `ne`, `id`, `mn`, `ru` (survey_i18n.py 참고)
- 관리자 출력물(조사표·엑셀)은 한국어 공식 서식으로 통일하며, 외국어 응답은 머리글에 응답 언어를 표시합니다.

## 관리자 로그인

관리자 화면은 **Supabase Auth 계정(이메일·비밀번호)** 으로 로그인합니다.
계정의 `app_metadata`에 `"role": "admin"`이 있어야 관리자 메뉴가 열립니다.
비밀번호를 잊었을 때는 Supabase 대시보드 > Authentication > Users 에서
해당 사용자의 비밀번호 재설정 메일을 보내거나 비밀번호를 새로 지정합니다.

## Streamlit Secrets

```toml
SUPABASE_URL = "..."
SUPABASE_KEY = "..."
APP_URL = "https://....streamlit.app"

# 선택
ORG_NAME = "○○병원 보건관리실"      # 설문 첫 화면·출력물 머리글

# 선택: 통증호소자 응답 접수 알림 메일 (메일에는 성명·건강정보를 넣지 않음)
ALERT_EMAIL_TO = "manager@example.com"   # 여러 명은 쉼표로 구분
SMTP_HOST = "smtp.gmail.com"
SMTP_PORT = 587
SMTP_USER = "sender@example.com"
SMTP_PASSWORD = "앱 비밀번호"
```

## 보관

유해요인조사 결과(증상 설문조사 결과 포함)는 5년 보존 대상입니다.
조사가 끝나면 **증상조사표 출력·보관 → 집계·보관 엑셀**에서 연도별로 내려받아 보관하세요.
'보고·공유용 엑셀'에는 개인이 드러나지 않는 숫자 집계만 들어갑니다.
